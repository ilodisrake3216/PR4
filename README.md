# Система управления центром языкового обучения

Курсовой проект по МДК 02.01 «Технология разработки программного обеспечения».  
**Автор:** Чернобай А.А., группа 24-ИСП-1.

Клиент-серверное приложение для автоматизации работы учебного центра иностранных языков. Веб-сервер на ASP.NET Core Web API управляет данными учебных групп, а десктопное приложение на Windows Forms предоставляет графический интерфейс администратора.

## Состав решения

| Проект | Назначение |
|---|---|
| `LanguageLearnApi` | Серверная часть (Web API на ASP.NET Core) |
| `LanguageSchool` | Клиентское десктопное приложение (Windows Forms) |

## Требования

- .NET 8 SDK или новее
- Visual Studio 2022 с установленными компонентами «Разработка классических приложений .NET» и «ASP.NET и разработка веб-приложений»

## Как запустить

1. Откройте файл решения (`.sln`) в Visual Studio.
2. В свойствах решения настройте совместный запуск проектов (**Несколько запускаемых проектов**): установите действие **Запустить** для `LanguageLearnApi` (первым) и `LanguageSchool` (вторым).
3. Нажмите **F5**. Интерактивная документация API откроется по адресу `http://localhost:5000/swagger` (или на порту, указанном в `launchSettings.json`).

## Адреса API

| Метод | Адрес | Описание |
|---|---|---|
| `GET` | `/api/groups` | Получить список всех учебных групп |
| `GET` | `/api/groups/{id}` | Получить информацию о группе по её ID |
| `POST` | `/api/groups` | Добавить новую учебную группу |
| `DELETE` | `/api/groups/{id}` | Удалить учебную группу |

## Справка для пользователя

Руководство пользователя находится в файле `LanguageSchool/Help/index.html` и открывается напрямую из клиентского приложения через верхнее меню **«Справка → Руководство пользователя»**. Контекстная справка по полям ввода вызывается клавишей **F1**.
